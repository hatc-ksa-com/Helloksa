# Amir Gujjar — HSE Portfolio

Static site (HTML, CSS, vanilla JS). No build step, no backend.

## Deploy on GitHub Pages
1. Create a repository named `amir-gujjar` and upload everything in this folder.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Site goes live at `https://YOUR-USERNAME.github.io/amir-gujjar/`.
4. Replace `YOUR-USERNAME` in `index.html` (canonical, Open Graph), `robots.txt`, `sitemap.xml`.

## Add your own images
- Certificates: save as `assets/certificates/cert-1.jpg` … `cert-5.jpg` (order: NEBOSH, OTHM, IOSH, OSHAcademy, Permit Receiver). Until a file exists, the card lets a visitor pick an image locally for preview only.
- Project photos: `assets/projects/project-1.jpg` … `project-6.jpg`. Use real project photos, or clearly illustrative images. Until added, a blueprint pattern is shown.
- Hero portrait: `assets/amir-gujjar.jpg` (unmodified original photo).

All paths are relative, so subdirectory hosting works.
